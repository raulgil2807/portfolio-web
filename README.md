# Portfolio — José Raúl Gil Jiménez

Portfolio profesional centrado en desarrollo de software, soporte técnico N1, experiencia con sistemas en producción y proyectos propios como PERA ERP.

## Tecnologías

- Next.js / React con Vinext
- TypeScript y CSS
- Canvas API para la topología interactiva
- Cloudflare Workers y Assets

## Desarrollo local

```bash
npm install
npm run dev
```

La aplicación completa se sirve con el entorno de desarrollo. También se incluye un `index.html` autónomo que puede abrirse o servirse directamente sin dependencias.

## Compilación

```bash
npm run build
```

La compilación genera el Worker y los recursos estáticos en `dist/`.
